# Servex Android App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Servex Android app — a dark-first Compose client that lists servers, shows per-server metrics with graphs, and raises threshold alerts.

**Architecture:** Single Gradle module `:app`, MVVM with `StateFlow`, manual `AppContainer` DI, `DataStore` + `EncryptedSharedPreferences` storage, OkHttp + kotlinx.serialization networking, hand-drawn Compose `Canvas` charts. Pure domain logic (status classification, chart scaling, validation) is JVM unit-tested.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), Navigation Compose, OkHttp, kotlinx.serialization, DataStore, WorkManager, security-crypto. No Hilt, no Room, no chart library.

**Spec:** `docs/superpowers/specs/2026-10-13-servex-design.md`

## Global Constraints

- Package / namespace / applicationId: `com.example.servex`.
- Toolchain: AGP 9.4.1, Kotlin 2.2.10, Gradle 9.6.0, Compose BOM 2026.02.01, compileSdk 37, minSdk 36, targetSdk 37, Java 11.
- **No emoji anywhere.** All icons are hand-authored `VectorDrawable`s on a 24dp grid, 2dp stroke.
- **Never distinguish status by color alone** — `StatusChip` always renders color + icon + text.
- Color tokens: background `#0F1115`, surface `#1A1D23`, surfaceVariant `#232732`, onSurface `#E6E9EF`, onSurfaceVariant `#8A9099`, primary `#4C8DFF`, success `#3DDC84`, warning `#FFC93C`, error `#FF5C5C`, offline `#6B7280`.
- Spacing scale 4/8/12/16/24 dp; card radius 12dp, button 10dp, icons 20/24dp.
- Status rule: normal < warning, warning ≥ 75, error ≥ 90; offline = no response/timeout/auth failure.
- Add only these dependencies (never a chart/Hilt/Room library): okhttp, kotlinx-serialization-json + plugin, datastore-preferences, navigation-compose, work-runtime-ktx, security-crypto, lifecycle-runtime-compose, mockwebserver (test).
- Version note: versions pinned in Task 1 are the intended ones. If Gradle cannot resolve one, substitute the latest stable in the same major line via the version catalog and record the change in that task's commit message.
- Low-memory target: one shared `OkHttpClient` unless a cert pin needs its own; no reflection-based libraries.

## Review Focus

1. **Agent returns `401`** — server shows OFFLINE (auth failure), never a crash or stale data. (Task 5.)
2. **Malformed / partial JSON from an unsupported agent** — `ignoreUnknownKeys` + defaults must not throw the whole screen away. (Task 3.)
3. **Empty server list** — Overview shows an empty state, not a blank crash. (Task 9.)
4. **Very long host name / metric value** — text ellipsizes, never overflows. (Task 8.)
5. **Threshold exactly at 75 / 90** — classified warning / error (inclusive). (Task 2.)
6. **Single-value history series** — chart must not divide by zero. (Task 8.)
7. **Token missing for a server** — repository returns a failure `Result`; UI shows the error path. (Task 5.)

```kotlin
// domain/Status.kt
package com.example.servex.domain

import com.example.servex.domain.model.MetricsSnapshot

enum class ServerStatus { NORMAL, WARNING, ERROR, OFFLINE }

data class AlertThreshold(val warningPct: Double = 75.0, val criticalPct: Double = 90.0)

object StatusCalculator {
    fun fromMetrics(m: MetricsSnapshot, t: AlertThreshold): ServerStatus {
        val values = buildList {
            add(m.cpu.usagePct)
            add(m.memory.pct)
            m.disks.forEach { add(it.pct) }
        }
        return when {
            values.any { it >= t.criticalPct } -> ServerStatus.ERROR
            values.any { it >= t.warningPct } -> ServerStatus.WARNING
            else -> ServerStatus.NORMAL
        }
    }

    fun worst(statuses: Iterable<ServerStatus>): ServerStatus {
        val order = listOf(ServerStatus.OFFLINE, ServerStatus.ERROR, ServerStatus.WARNING, ServerStatus.NORMAL)
        val set = statuses.toSet()
        return order.firstOrNull { it in set } ?: ServerStatus.OFFLINE
    }
}
```

```kotlin
// data/ServexApi.kt
package com.example.servex.data

import com.example.servex.domain.model.*
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import kotlinx.serialization.json.Json
import okhttp3.CertificatePinner
import okhttp3.MediaType.Companion.toMediaType
import okhttp3.OkHttpClient
import okhttp3.Request
import okhttp3.RequestBody.Companion.toRequestBody
import java.util.concurrent.TimeUnit

class ApiException(val code: Int, message: String) : Exception(message)

object HttpClients {
    val shared: OkHttpClient = OkHttpClient.Builder()
        .connectTimeout(5, TimeUnit.SECONDS)
        .readTimeout(5, TimeUnit.SECONDS)
        .callTimeout(8, TimeUnit.SECONDS)
        .build()

    fun forServer(server: Server): OkHttpClient {
        val fp = server.certFingerprint
        if (fp.isNullOrBlank()) return shared
        val host = server.baseUrl.removePrefix("https://").removePrefix("http://")
            .substringBefore('/').substringBefore(':')
        val pinner = CertificatePinner.Builder().add(host, "sha256/$fp").build()
        return shared.newBuilder().certificatePinner(pinner).build()
    }
}

class ServexApi(private val client: OkHttpClient) : ServexApiContract {
    private val json = Json { ignoreUnknownKeys = true; explicitNulls = false }

    private suspend fun get(server: Server, token: String, path: String): String = withContext(Dispatchers.IO) {
        val req = Request.Builder()
            .url(server.baseUrl.trimEnd('/') + path)
            .header("Authorization", "Bearer $token")
            .get().build()
        client.newCall(req).execute().use { resp ->
            val body = resp.body?.string().orEmpty()
            if (!resp.isSuccessful) throw ApiException(resp.code, body.ifBlank { resp.message })
            body
        }
    }

    override suspend fun summary(server: Server, token: String): ServerSummary =
        json.decodeFromString(get(server, token, "/api/v1/summary"))

    override suspend fun metrics(server: Server, token: String): MetricsSnapshot =
        json.decodeFromString(get(server, token, "/api/v1/metrics"))

    override suspend fun history(server: Server, token: String, metric: String, points: Int): HistoryResponse =
        json.decodeFromString(get(server, token, "/api/v1/history?metric=$metric&points=$points"))

    override suspend fun health(server: Server, token: String): Boolean =
        runCatching { get(server, token, "/api/v1/health") }.isSuccess

    override suspend fun action(server: Server, token: String, action: String, args: Map<String, String>): ActionResult =
        withContext(Dispatchers.IO) {
            val payload = json.encodeToString(ActionRequest.serializer(), ActionRequest(action, args))
            val req = Request.Builder()
                .url(server.baseUrl.trimEnd('/') + "/api/v1/action")
                .header("Authorization", "Bearer $token")
                .post(payload.toRequestBody("application/json".toMediaType()))
                .build()
            client.newCall(req).execute().use { resp ->
                val body = resp.body?.string().orEmpty()
                if (!resp.isSuccessful) throw ApiException(resp.code, body.ifBlank { resp.message })
                json.decodeFromString(body)
            }
        }
}
```

```kotlin
// data/ServerStore.kt
package com.example.servex.data

import android.content.Context
import androidx.datastore.preferences.core.edit
import androidx.datastore.preferences.core.stringPreferencesKey
import androidx.datastore.preferences.preferencesDataStore
import com.example.servex.domain.model.Server
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.map
import kotlinx.serialization.json.Json

private val Context.serverDataStore by preferencesDataStore(name = "servex_servers")

class ServerStore(private val context: Context) : ServerStoreContract {
    private val key = stringPreferencesKey("servers_json")

    override val servers: Flow<List<Server>> =
        context.serverDataStore.data.map { decode(it[key]) }

    override suspend fun upsert(server: Server) {
        context.serverDataStore.edit { prefs ->
            val current = decode(prefs[key]).filterNot { it.id == server.id } + server
            prefs[key] = encode(current)
        }
    }

    override suspend fun delete(id: String) {
        context.serverDataStore.edit { prefs ->
            prefs[key] = encode(decode(prefs[key]).filterNot { it.id == id })
        }
    }

    companion object {
        private val json = Json { ignoreUnknownKeys = true }
        fun encode(list: List<Server>): String = json.encodeToString(list)
        fun decode(raw: String?): List<Server> =
            if (raw.isNullOrBlank()) emptyList()
            else runCatching { json.decodeFromString<List<Server>>(raw) }.getOrDefault(emptyList())
    }
}
```

```kotlin
// data/ServerRepository.kt
package com.example.servex.data

import com.example.servex.domain.AppSettings
import com.example.servex.domain.model.*
import kotlinx.coroutines.flow.Flow

class ServerRepository(
    private val serverStore: ServerStoreContract,
    private val settingsStore: SettingsStoreContract,
    private val tokenStore: TokenStoreContract,
    private val api: ServexApiContract,
) {
    val servers: Flow<List<Server>> = serverStore.servers
    val settings: Flow<AppSettings> = settingsStore.settings

    suspend fun save(server: Server, token: String?) {
        serverStore.upsert(server)
        if (token != null) tokenStore.put(server.id, token)
    }

    suspend fun delete(id: String) {
        serverStore.delete(id)
        tokenStore.remove(id)
    }

    suspend fun updateSettings(transform: (AppSettings) -> AppSettings) = settingsStore.update(transform)

    private fun token(server: Server): String? = tokenStore.get(server.id)?.takeIf { it.isNotBlank() }

    suspend fun metrics(server: Server): Result<MetricsSnapshot> = call(server) { api.metrics(it, token(server)!!) }

    suspend fun history(server: Server, metric: String, points: Int): Result<HistoryResponse> =
        call(server) { api.history(it, token(server)!!, metric, points) }

    suspend fun runAction(server: Server, action: String, args: Map<String, String>): Result<ActionResult> =
        call(server) { api.action(it, token(server)!!, action, args) }

    suspend fun testConnection(server: Server, token: String): Result<Unit> =
        runCatching { api.summary(server, token); Unit }

    private inline fun <T> call(server: Server, block: (Server) -> T): Result<T> {
        token(server) ?: return Result.failure(IllegalStateException("missing token"))
        return runCatching { block(server) }
    }
}
```

```kotlin
// ui/charts/ChartMath.kt
package com.example.servex.ui.charts

fun chartPoints(values: List<Float>, width: Float, height: Float, pad: Float): List<Pair<Float, Float>> {
    if (values.isEmpty()) return emptyList()
    val usableW = (width - 2f * pad).coerceAtLeast(1f)
    val usableH = (height - 2f * pad).coerceAtLeast(1f)
    val min = values.min()
    val max = values.max()
    val span = (max - min).takeIf { it > 0.0001f } ?: 1f
    val step = if (values.size > 1) usableW / (values.size - 1) else 0f
    return values.mapIndexed { i, v ->
        val x = pad + step * i
        val norm = (v - min) / span
        val y = pad + (1f - norm) * usableH
        x to y
    }
}
```

```kotlin
package com.example.servex.ui.overview

import androidx.lifecycle.ViewModel

import com.example.servex.data.ServerRepository
import com.example.servex.domain.AlertThreshold
import com.example.servex.domain.ServerStatus
import com.example.servex.domain.StatusCalculator

import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine

import kotlinx.coroutines.flow.stateIn

data class StatusSummary(val normal: Int, val warning: Int, val error: Int, val offline: Int)

fun summarize(statuses: List<ServerStatus>): StatusSummary = StatusSummary(
    normal = statuses.count { it == ServerStatus.NORMAL },
    warning = statuses.count { it == ServerStatus.WARNING },
    error = statuses.count { it == ServerStatus.ERROR },
    offline = statuses.count { it == ServerStatus.OFFLINE },
)

data class ServerRow(val server: Server, val status: ServerStatus, val spark: List<Float>)

data class OverviewUiState(
    val rows: List<ServerRow> = emptyList(),
    val summary: StatusSummary = StatusSummary(0, 0, 0, 0),
    val loading: Boolean = true,
)

class OverviewViewModel(private val repository: ServerRepository) : ViewModel() {
    private val rows = MutableStateFlow<List<ServerRow>>(emptyList())
    private val loading = MutableStateFlow(true)
    private var activeServers: List<Server> = emptyList()

    val uiState: StateFlow<OverviewUiState> = combine(rows, loading) { r, l ->
        OverviewUiState(r, summarize(r.map { it.status }), l)
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), OverviewUiState())

    init {
        viewModelScope.launch {
            repository.servers.collect { servers ->
                activeServers = servers.filter { it.enabled }
                refresh()
            }
        }
    }

    fun refresh(): Unit = viewModelScope.launch {
        loading.value = true
        val settings = repository.settings.first()
        val threshold = AlertThreshold(settings.warningPct, settings.criticalPct)
        rows.value = activeServers.map { server ->
            val status = repository.metrics(server).fold(
                onSuccess = { StatusCalculator.fromMetrics(it, threshold) },
                onFailure = { ServerStatus.OFFLINE },
            )
            val spark = repository.history(server, "cpu", 30)
                .getOrNull()?.points?.map { it.v.toFloat() }.orEmpty()
            ServerRow(server, status, spark)
        }
        loading.value = false
    }
}
```

```kotlin
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.servex.data.ServerRepository
import com.example.servex.domain.AlertThreshold
import com.example.servex.domain.ServerStatus
import com.example.servex.domain.StatusCalculator
import com.example.servex.domain.model.HistoryPoint
import com.example.servex.domain.model.MetricsSnapshot
import com.example.servex.domain.model.Server
import kotlinx.coroutines.Job
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

fun toFloats(points: List<HistoryPoint>): List<Float> = points.map { it.v.toFloat() }

data class DetailUiState(
    val server: Server? = null,
    val status: ServerStatus = ServerStatus.OFFLINE,
    val metrics: MetricsSnapshot? = null,
    val error: String? = null,
    val history: Map<String, List<Float>> = emptyMap(),
)

class DetailViewModel(
    private val repository: ServerRepository,
    private val serverId: String,
    private val refreshIntervalS: Int,
) : ViewModel() {
    private val state = MutableStateFlow(DetailUiState())
    val uiState: StateFlow<DetailUiState> = state.asStateFlow()
    private var loop: Job? = null

    init {
        viewModelScope.launch {
            val server = repository.servers.first().firstOrNull { it.id == serverId }
            state.update { it.copy(server = server) }
            if (server != null) startPolling(server)
        }
    }

    private fun startPolling(server: Server) {
        loop?.cancel()
        loop = viewModelScope.launch {
            while (true) {
                val settings = repository.settings.first()
                val threshold = AlertThreshold(settings.warningPct, settings.criticalPct)
                repository.metrics(server).fold(
                    onSuccess = { m ->
                        state.update {
                            it.copy(metrics = m, status = StatusCalculator.fromMetrics(m, threshold), error = null)
                        }
                    },
                    onFailure = { e ->
                        state.update { it.copy(status = ServerStatus.OFFLINE, error = e.message) }
                    },
                )
                loadHistory(server)
                delay(server.pollIntervalS.coerceAtLeast(1) * 1000L)
            }
        }

    private suspend fun loadHistory(server: Server) {
```

```kotlin
// ui/edit/EditServerViewModel.kt
package com.example.servex.ui.edit

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.servex.data.ServerRepository
import com.example.servex.domain.model.Server
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch
import java.util.UUID

fun validateServer(name: String, baseUrl: String): String? = when {
    name.isBlank() -> "err_name"
    baseUrl.isBlank() || !(baseUrl.startsWith("http://") || baseUrl.startsWith("https://")) -> "err_url"
    else -> null
}

data class EditUiState(
    val id: String = UUID.randomUUID().toString(),
    val name: String = "",
    val baseUrl: String = "",
    val token: String = "",
    val certFingerprint: String = "",
    val pollIntervalS: Int = 5,
    val errorKey: String? = null,
    val testResult: String? = null,
    val saving: Boolean = false,
)

class EditServerViewModel(
    private val repository: ServerRepository,
    private val serverId: String?,
) : ViewModel() {
    private val state = MutableStateFlow(EditUiState())
    val uiState: StateFlow<EditUiState> = state.asStateFlow()

    init {
        if (serverId != null) viewModelScope.launch {
            repository.servers.first().firstOrNull { it.id == serverId }?.let { s ->
                state.value = EditUiState(
                    id = s.id, name = s.name, baseUrl = s.baseUrl,
                    certFingerprint = s.certFingerprint.orEmpty(), pollIntervalS = s.pollIntervalS,
                )
            }
        }
    }

    fun onName(v: String) = state.update { it.copy(name = v) }
    fun onUrl(v: String) = state.update { it.copy(baseUrl = v) }
    fun onToken(v: String) = state.update { it.copy(token = v) }
    fun onFingerprint(v: String) = state.update { it.copy(certFingerprint = v) }
    fun onPoll(v: Int) = state.update { it.copy(pollIntervalS = v) }

    fun testConnection() {
        val s = state.value
        viewModelScope.launch {
            repository.testConnection(s.toServer(), s.token).fold(
                onSuccess = { state.update { it.copy(testResult = "ok") } },
                onFailure = { state.update { it.copy(testResult = it.message ?: "fail") } },
            )
        }
    }

    fun save(onDone: () -> Unit) {
        val s = state.value
        val err = validateServer(s.name, s.baseUrl)
        if (err != null) { state.update { it.copy(errorKey = err) }; return }
        viewModelScope.launch {
            state.update { it.copy(saving = true) }
            repository.save(s.toServer(), s.token.ifBlank { null })
            state.update { it.copy(saving = false) }
            onDone()
        }
    }

    private fun EditUiState.toServer() = Server(
        id = id, name = name.trim(), baseUrl = baseUrl.trim().trimEnd('/'),
        certFingerprint = certFingerprint.trim().ifBlank { null }, pollIntervalS = pollIntervalS,
    )
}
```

```kotlin
    const val EDIT = "edit?serverId={serverId}"
    const val SETTINGS = "settings"
    fun detail(id: String) = "detail/$id"
    fun edit(id: String?) = if (id == null) "edit" else "edit?serverId=$id"

fun ServexNavHost(container: AppContainer, modifier: Modifier = Modifier) {
    val nav = rememberNavController()
    val factory = VmFactory(container)
    NavHost(nav, startDestination = Routes.OVERVIEW, modifier = modifier) {
        composable(Routes.OVERVIEW) {
            val vm: OverviewViewModel = viewModel(factory = factory)
            OverviewScreen(
                viewModel = vm,
                onOpenServer = { nav.navigate(Routes.detail(it)) },
                onOpenSettings = { nav.navigate(Routes.SETTINGS) },
                onAddServer = { nav.navigate(Routes.edit(null)) },
            )
        }
        composable(Routes.DETAIL, arguments = listOf(navArgument("serverId") { type = NavType.StringType })) { entry ->
            val id = entry.arguments?.getString("serverId").orEmpty()
            DetailScreen(
                viewModel = factory.detail(id, 5),
                onBack = { nav.popBackStack() },
                onEdit = { nav.navigate(Routes.edit(it)) },
            )
        }
        composable(
            Routes.EDIT,

        ) { entry ->
            val id = entry.arguments?.getString("serverId").orEmpty().ifBlank { null }
            EditServerScreen(viewModel = factory.edit(id), onBack = { nav.popBackStack() })
        }
        composable(Routes.SETTINGS) {
            val vm: SettingsViewModel = viewModel(factory = factory)
```

```kotlin
package com.example.servex.worker

import android.app.NotificationChannel
import android.app.NotificationManager
import android.content.Context
import androidx.core.app.NotificationCompat
import com.example.servex.R
import com.example.servex.domain.ServerStatus

class Notifier(private val context: Context) {
    private val channelId = "servex_alerts"

    fun notify(serverName: String, status: ServerStatus) {
        val mgr = context.getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
        mgr.createNotificationChannel(
            NotificationChannel(channelId, "Servex Alerts", NotificationManager.IMPORTANCE_DEFAULT),
        )
        val bodyRes = when (status) {
            ServerStatus.WARNING -> R.string.status_warning
            ServerStatus.ERROR -> R.string.status_error
            ServerStatus.OFFLINE -> R.string.status_offline
            else -> R.string.status_normal
        }
        val n = NotificationCompat.Builder(context, channelId)
            .setSmallIcon(R.drawable.ic_status_warning)
            .setContentTitle(serverName)
            .setContentText(context.getString(bodyRes))
            .setAutoCancel(true)
            .build()
        mgr.notify(serverName.hashCode(), n)
    }
}
```

```kotlin
// worker/AlertWorker.kt
package com.example.servex.worker

import android.content.Context
import androidx.work.CoroutineWorker
import androidx.work.WorkerParameters
import com.example.servex.ServexApp
import com.example.servex.domain.AlertThreshold
import com.example.servex.domain.ServerStatus
import com.example.servex.domain.StatusCalculator
import kotlinx.coroutines.flow.first

fun shouldNotify(previous: ServerStatus?, current: ServerStatus): Boolean {
    if (previous == current) return false
    if (previous == null && current == ServerStatus.NORMAL) return false
    return true
}

class AlertWorker(appContext: Context, params: WorkerParameters) : CoroutineWorker(appContext, params) {
    override suspend fun doWork(): Result {
        val container = (applicationContext as ServexApp).container
        val settings = container.settingsStore.settings.first()
        if (!settings.alertsEnabled) return Result.success()
        val threshold = AlertThreshold(settings.warningPct, settings.criticalPct)
        val servers = container.serverStore.servers.first().filter { it.enabled }
        val notifier = Notifier(applicationContext)
        for (server in servers) {
            val current = container.repository.metrics(server).fold(
                onSuccess = { StatusCalculator.fromMetrics(it, threshold) },
                onFailure = { ServerStatus.OFFLINE },
            )
            val previous = container.lastStatusStore.get(server.id)
            if (shouldNotify(previous, current)) notifier.notify(server.name, current)
            container.lastStatusStore.set(server.id, current)
        }
        return Result.success()
    }
}
```

```kotlin
// worker/AlertScheduler.kt
package com.example.servex.worker

import android.content.Context
import androidx.work.Constraints
import androidx.work.ExistingPeriodicWorkPolicy
import androidx.work.NetworkType
import androidx.work.PeriodicWorkRequestBuilder
import androidx.work.WorkManager
import java.util.concurrent.TimeUnit

object AlertScheduler {
    private const val WORK = "servex_alert"

    fun schedule(context: Context, enabled: Boolean) {
        val wm = WorkManager.getInstance(context)
        if (!enabled) { wm.cancelUniqueWork(WORK); return }
        val request = PeriodicWorkRequestBuilder<AlertWorker>(15, TimeUnit.MINUTES)
            .setConstraints(Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build())
            .build()
        wm.enqueueUniquePeriodicWork(WORK, ExistingPeriodicWorkPolicy.UPDATE, request)
    }
}
```
